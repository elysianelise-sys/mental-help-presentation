25

After testing the live app on a desktop browser I found six things to fix. The page gradient stopped short of the phone frame and left seams, so one gradient now sits behind the whole app. A mouse could not reach the second Home card, so the cards can be dragged and have two dots. Sessions had two Back buttons and the confirm sheet had both a close button and Not now, so I removed the extras. View all did nothing, so it now shows all four themes. The Search pill drew a square outline, so it now has a soft ring. The Check-in feelings were cut off in a sideways row, so all six sit in a grid. Close icons that drew as solid squares were also fixed.
